* About

ROM Frontend for bypass/passthrough charging toggle.

* Usage

** 1) Clone this repository to the specified directory

#+BEGIN_SRC shell
git clone https://github.com/YAAP/packages_apps_BypassCharge packages/apps/BypassCharge
#+END_SRC

** 2) Build the package and add sepolicy if needed

* Purpose

+ To provide a toggle for bypass/passthrough charging instead of using LineageOS' HIDL HAL.
